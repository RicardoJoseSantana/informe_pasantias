\begin{resumo}

El proyecto consistió en el desarrollo integral de un sistema de control de movimiento en lazo cerrado basado en el microcontrolador ESP32. El sistema es capaz de comandar un motor de paso de alta potencia a través de un driver comercial, utilizando la lectura de posición de un encoder incremental como realimentación. La arquitectura de software, desarrollada sobre el framework ESP-IDF y el sistema operativo FreeRTOS, es modular y concurrente, permitiendo una operación robusta y en tiempo real.
Para facilitar la interacción y el diagnóstico, se implementó una interfaz de usuario dual que incluye una pantalla LCD para la visualización de datos y una consola serie para la configuración de parámetros. El resultado final del proyecto no solo es un sistema funcional, sino también un conjunto completo de documentación técnica y software reutilizable.

\textbf{Palabras-clave}: Control. Motor. Encoder. Pantalla.

\end{resumo}
