\begin{resumo}

\noindent El proyecto consistió en el desarrollo integral de un sistema de control de movimiento basado en el microcontrolador \textbf{ESP32}. El sistema tiene la capacidad de comandar un motor de paso de alta potencia a través de un \textit{driver} comercial, utilizando la lectura de posición de un encoder incremental. La arquitectura de software se desarrolló sobre el \textit{framework} ESP-IDF, lo que permitió una operación modular y concurrente. Como implementación adicional, se diseñó una \textbf{interfaz de usuario} que incluye una pantalla LCD para la visualización de datos y una consola serie para la configuración de parámetros. El resultado final del proyecto abarca un conjunto completo de documentación técnica y \textit{software} reutilizable.

\textbf{Palabras-clave}: Control. Motor. Encoder. Pantalla.

\end{resumo}
